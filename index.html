GitHub Pages Demo

静态资源也可以像网站一样直接访问

把 HTML、CSS、图片和 JavaScript 放进 GitHub 仓库，再开启 GitHub Pages， GitHub 就会把这些文件托管成一个可访问的网址。

查看 Pages 文档 了解原理

GitHub 怎么展示静态资源

1

仓库存文件

入口通常是 index.html，样式、脚本和图片使用相对路径引用。

2

Pages 读取来源

GitHub Pages 可以读取分支目录，或通过 Actions 把静态文件上传为站点。

3

生成访问域名

项目站点地址通常是 https://用户名.github.io/仓库名/。
